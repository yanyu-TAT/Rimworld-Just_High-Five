# B-03 测试指南

> 本模组无自动化测试框架，测试 = **编译验证 + 资源体检 + 游戏内实测 + 日志检查**。

## 一、编译验证（每次改动后必做）

```powershell
$env:DOTNET_CLI_HOME = "D:\CODE\rim\Clap_Your_Hands\.dsh-dotnet"
dotnet build "Clap_Your_Hands\Clap_Your_Hands.csproj" -v minimal
```

**通过标准**：`已成功生成` + `0 个警告` + `0 个错误`，且 `Clap_Your_Hands/Assemblies/Clap_Your_Hands.dll` 时间戳更新。

## 二、XML 解析验证

```powershell
Get-ChildItem "Clap_Your_Hands" -Recurse -File -Filter *.xml |
  Where-Object { $_.FullName -match "Defs|Languages" } | ForEach-Object {
    try { [xml](Get-Content $_.FullName) | Out-Null; "OK   $($_.Name)" }
    catch { "FAIL $($_.Name): $_" }
  }
```

**通过标准**：Defs 与 Languages 下的 XML 全部 `OK`；中英 Keyed 文件**逐键对称**。

## 三、资源格式体检（改动贴图 / 音频后必做）

```powershell
# 贴图：尺寸应为 2 的幂，且带 alpha 通道（读 PNG 头，无需图像库）
Get-ChildItem "Clap_Your_Hands\Textures" -Recurse -Filter *.png | ForEach-Object {
  $b = [System.IO.File]::ReadAllBytes($_.FullName)
  $w = [int]$b[16]*16777216 + [int]$b[17]*65536 + [int]$b[18]*256 + [int]$b[19]
  $h = [int]$b[20]*16777216 + [int]$b[21]*65536 + [int]$b[22]*256 + [int]$b[23]
  "$($_.Name): $w x $h  colorType=$($b[25])"
}
```

```powershell
# 音频：应为单声道 / 44100 Hz / 16-bit，且 < 300 KB（超过会走流式加载）
$code = @'
import wave, glob, os
for p in glob.glob(r"Clap_Your_Hands\Sounds\**\*.wav", recursive=True):
    w = wave.open(p)
    print("%s  %dch %dHz %dbit  %.2fs  %.1fKB" % (os.path.basename(p), w.getnchannels(),
          w.getframerate(), w.getsampwidth()*8, w.getnframes()/w.getframerate(), os.path.getsize(p)/1024))
'@
$code | & ".venv\Scripts\python.exe" -
```

**通过标准**：贴图 `colorType=6`（RGBA）；音频三项参数符合规范且体积 < 300 KB（依据见 `C-05` §5.1、§6.4.1）。

## 四、游戏内测试流程

1. 游戏加载到主菜单 → 开发模式开启 → 模组列表中启用本模组
2. **检查加载日志无红字**：检索 `Player.log` 中的 `Clap` 与 `[ClapYourHands]`
3. 进入殖民地（或开发者模式快速开局），准备 2 名以上可社交的殖民者
4. 观察社交日志中是否出现击掌互动
5. **加速观察特效 / 音效**：开发者菜单 → Settings 分页 → `Clap` 分类 → 勾选
   `More Clap Hands (weight x100)`（击掌频繁出现）+ `Always Perfect clap`（必定完美档）
6. 观察完美击掌的**音效**与**黑闪特效**（暗红闪电 + 抛物线下落的火花）
7. 打开**模组设置页**（选项 → 模组 → Clap Your Hands → 模组选项），拖动音量滑块并点「试听」
8. 用调试指令（若有）强制触发各档结果，逐项核对效果

### 检查清单

| # | 检查项 | 期望 |
| --- | --- | --- |
| 1 | 模组加载 | 无红字，`[ClapYourHands] loaded.` 出现 |
| 2 | Def 加载 | 无「Could not find def」「Duplicate defName」类错误 |
| 3 | 自动触发 | 社交日志出现击掌，频率不刷屏 |
| 4 | 四档结果 | 均能出现，比例接近基础权重（小样本需耐心） |
| 5 | 情绪 | 糟糕 −3 / 普通 0 / 不错 +3 / 完美 +10 |
| 6 | 好感度 | 不错 / 完美后双方 opinion 上升（注意 `SocialImpact` 缩放） |
| 7 | 12h 增益 | 工作速度与移速变化与档位匹配，时长 12h |
| 8 | 增益叠加 | 高级覆盖低级；同级覆盖时长；低级不动高级 |
| 9 | 冷却 | 冷却中不再击掌；OR 判定行为符合预期 |
| 10 | 排除 | 敌对 / 仇视关系不触发；发起者手上抱着 pawn 时不触发 |
| 11 | 存读档 | 冷却与增益状态保持正确 |
| 12 | 黑闪特效 | 完美档在两人中点出现暗红闪电；火花抛出后按抛物线起落，撞墙即停 |

| 14 | 设置页 | 滑块默认 50%、可在 0%~100% 拖动并显示实时百分比；「试听」按下即播一次（仅在有地图时显示） |
| 15 | 设置持久化 | 改完音量后重启游戏，数值仍保持 |

## 五、日志检查

```powershell
Select-String -Path "<RimWorld 目录>\Player.log" -Pattern "Clap|clap" -Context 2,2
```

重点关注：`Exception`、`Could not find`、`Duplicate`、本模组前缀的 `Log.Error`（现有分支文案：`黑闪 FleckDef 未加载`、`击掌音效 Def 未加载`、`击掌结算收到无效的小人`、`调试开关字段无效`）。

## 六、回归重点

改动以下内容时必须重跑清单：`InteractionDef`/`HediffDef`/`ThoughtDef`/`FleckDef`/`SoundDef` 的 defName 或字段、概率常量、冷却逻辑、`ExposeData` 结构（含 `ClapSettings` 的字段名）、贴图或音频文件的**文件名/目录/格式**（`texPath`、`clipFolderPath` 直接依赖路径）。
