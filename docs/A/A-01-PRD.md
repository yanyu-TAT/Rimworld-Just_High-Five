# A-01 PRD — Clap Your Hands

> 需求基准。详细数值与实现路径见 `plans/击掌功能开发计划.md`。

## 一、一句话定位

为 RimWorld 1.6 加入「击掌」社交互动，让殖民者之间有更多正面、轻松、带随机性的互动方式，并在「完美击掌」时给予短期增益作为奖励。

## 二、核心需求

1. **新增社交互动「击掌」**，由殖民者在日常社交中自动发起（进入原版随机社交池）
2. **四档结果**：糟糕 10%（情绪 −3）、普通 30%（0）、不错 50%（+3）、完美 10%（+10）
3. **好感度**：不错的击掌双方 +3；完美的击掌双方 +5
4. **完美击掌奖励**：额外获得 12 小时随机增益
   - 快速 50%：工作速度 +10%、移速 +0.1
   - 迅捷 30%：工作速度 +25%、移速 +0.2
   - 神速 15%：工作速度 +50%、移速 +0.5
   - 灵感 5%：随机灵感
5. **冷却**：击掌后双方各 24 小时冷却；判定为 OR（两人中有一人冷却完毕即可再次击掌）
6. **增益叠加**：效果取最高；同级或更高级效果覆盖持续时间
7. **关系影响**：双方好感度越高，正面结果概率越高
8. **排除条件**：敌对 / 仇视关系的小人不会进行此互动；手上抱着 pawn 时也不会
9. **完美击掌的表现反馈**：在双方中点播放拍手音效与「黑闪」特效（暗红闪电纹样 + 抛物线下落的火花）
10. **模组设置**：音效音量缩放 0%~100%（滑块）+ 试听按钮（按下即播放一次），走原版 `ModSettings` 框架

## 三、非功能性需求

- **零第三方依赖**：不引入 Harmony / HugsLib；设置页使用原版 `ModSettings` 框架
- **存档安全**：所有运行时状态随存读档正确保持
- **本地化**：中英双语，玩家可见文本 100% 走语言文件
- **稳定性**：游戏加载无红字；不产生异常日志

## 四、验收标准

- [ ] 游戏中殖民者会自然发生「击掌」，社交日志正确显示
- [ ] 四档结果的出现比例在无好感度影响时符合 10/30/50/10
- [ ] 好感度提高时，不错 / 完美档比例上升，糟糕档下降
- [ ] 情绪、好感度、12h 增益均按规则生效
- [ ] 增益叠加符合「取最高 + 同级/高级覆盖时长」
- [ ] 冷却按 OR 判定生效
- [ ] 敌对 / 仇视关系不触发；手上抱着 pawn 时不触发
- [ ] 完美击掌在双方中点播放音效与黑闪特效（闪电 + 火花）
- [ ] 模组设置页可打开，滑块可在 0%~100% 调节且试听按钮即时生效，设置随选项文件保存
- [ ] 存读档后状态正确
- [ ] `dotnet build` 0 警告 0 错误
- [ ] 中英语言文件逐键对称

## 五、不在范围内

- 不改动原版任何既有互动
- 不自建独立 UI 界面（模组设置页由原版 `ModSettings` / `Dialog_ModSettings` 承载，仍属零依赖）
- 不引入任何第三方库或素材；贴图与音效均为自制或可商用授权素材
