# C-06 本地化术语表

> 中英译名基准、风格要求与译名取舍记录。新增玩家可见文本前先在此登记。

## 风格要求

- 中文：贴近原版 RimWorld 官方简中风格，简洁、口语化、不用网络流行语的生硬直译
- 英文：小写短句（延续原版互动名风格，如 `chitchat` / `deep talk` / `slight`）
- Def 的 `label` 与日志文本分列，避免中英长度差异导致日志排版异常

## 术语基准

| 概念 | 中文 | English | 出处 / 备注 |
| --- | --- | --- | --- |
| 互动名 | 击掌 | high five | `InteractionDef.label`；英文按原版风格小写 |
| 结果档位 1 | 糟糕的击掌 | bad high five | 情绪 −3 |
| 结果档位 2 | 普通的击掌 | plain high five | 情绪 0 |
| 结果档位 3 | 不错的击掌 | good high five | 情绪 +3，好感 +3 |
| 结果档位 4 | 完美的击掌 | perfect high five | 情绪 +10，好感 +5 |
| 增益等级 1 | Lv1 | Lv1 | 工作速度 +10%、移速 +0.1 |
| 增益等级 2 | Lv2 | Lv2 | 工作速度 +25%、移速 +0.2 |
| 增益等级 3 | Lv3 | Lv3 | 工作速度 +50%、移速 +0.5 |
| 增益载体 | 击掌余韵 | high five rush | 完美击掌的 12 小时增益 |
| 冷却状态 | 击掌冷却 | high five cooldown | 隐藏 Hediff，玩家通常不可见 |

## 键名约定

- 代码内文本（`Keyed`）：`ClapYourHands.<域>.<语义>`，例如 `ClapYourHands.Clap.Perfect`
- Def 文本（`DefInjected`）：键为 `<DefName>.<字段>`，文件与 `Defs/` 一一对应
- 中英语言文件必须**逐键对称**

## 译名取舍记录

| 版本 | 决策 | 理由 |
| --- | --- | --- |
| 0.0.1 | 增益名采用「快速 / 迅捷 / 神速」三级递进 | 最初希望三个等级在中文里形成可感知的强弱梯度 |
| 0.0.1 | **改为 `Lv1` / `Lv2` / `Lv3`** | 等级用统一标识更直观；中英完全一致、长度固定，Hediff 标签栏对齐更整齐 |
| 0.0.1 | 英文用词由 `clap` 统一为 **`high five`** | 本互动是「两人各出一只手互击」，英文标准说法为 high five；单独用 clap 易被理解为单人「鼓掌」。中文「击掌」本就对应 high five，无需改动 |
