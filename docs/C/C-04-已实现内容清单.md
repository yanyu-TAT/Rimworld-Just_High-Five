### 功能（v0.0.1 全部实际效果）

- [x] 仇视排除（`opinion <= -20`，阈值与原版 `RivalOpinionThreshold` 一致）

- [x] 调试指令（强制击掌 / 清除冷却 / 增减增益）

### 模组设置（v0.0.2）

- [x] `ClapSettings`（原版 `ModSettings`）：音效音量缩放系数（默认 50%，字段初值与 `Scribe` 默认值一致），随设置文件持久化

- [x] 音量作用于播放链路：`SoundInfo.volumeFactor`（乘算，不影响玩家的 `Prefs.VolumeGame`）
