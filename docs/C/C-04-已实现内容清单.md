### 手动击掌（v0.0.3）

- [x] 浮动菜单「击掌」：单选中一个殖民者后右键另一个殖民者（`FloatMenuOptionProvider_Clap`）
- [x] 前往工作 `Clap_ManualClap`：走到对方身边、stun 对方、进入判定（`JobDriver_ClapWith`）
- [x] 音游判定条（`Window_ClapRhythm`）：不暂停游戏、7 段按概率染色、完美段中点 25%~75% 随机、深金描边、可配置时长游标、点击/超时判定
- [x] 命中段放大后置于判定区最上层；判定完成即结算、解除 stun，判定条放大跳动后保留 2 秒淡出
- [x] 判定期间用原版 `TimeSlower.SignalForceNormalSpeed()` 临时限速，结束后自然过期
- [x] 判定时长可在设置页调整（1~10 秒，0.5 秒步进，默认 2.5 秒），随设置文件持久化
- [x] 冷却中可发起：判定与表现照常，不写心情/好感/增益/冷却；仇视灰显

### 模组设置（v0.0.2）

- [x] `ClapSettings`（原版 `ModSettings`）：音效音量缩放系数（默认 50%，字段初值与 `Scribe` 默认值一致），随设置文件持久化

- [x] 试听按钮仅在有地图时显示（无地图时无法定位音源，见 `C-05` §10.4）
- [x] 入口：覆写 `SettingsCategory()`，原版模组菜单出现「Mod 选项」
- [x] 音量作用于播放链路：`SoundInfo.volumeFactor`（乘算，不影响玩家的 `Prefs.VolumeGame`）
